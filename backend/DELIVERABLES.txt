================================================================================
                        INSTALLATION & USAGE
================================================================================

PREREQUISITE:
  • Python 3.8+
  • Google Gemini API key

SETUP (5 MINUTES):
  1. export GEMINI_API_KEY="your-api-key"
  2. cd backend
  3. python view_db.py              (verify database)
  4. python -m uvicorn app.main:app --reload
  5. curl -X POST http://localhost:8000/api/kpi/determine \
       -H "Content-Type: application/json" \
       -d '{"jd_id": 1, "candidate_id": 1}'

TESTING:
  • python test_kpi_demo.py         (run demo script)
  • pytest tests/                   (run unit tests)
